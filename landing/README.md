# Sauron Landing Page

Professional landing page for Sauron Network Intelligence Platform - now with **interactive demo dashboard**!

## 🎨 Design

- **Light theme** - Clean, professional white/slate color scheme
- **Focus on benefits** - What it does, not how it's built
- **Interactive demo** - Fully functional dashboard with mock data
- **Smooth animations** - Scroll reveals, hover effects, micro-interactions

## ✨ Features

### Sections

1. **Hero** - Animated app preview with floating elements
2. **Features** - 6 key capabilities with scroll animations
3. **How It Works** - 4-step simple process
4. **Interactive Dashboard** - Fully functional demo with:
   - Live firewall status monitoring
   - Interactive topology visualization (click nodes!)
   - Path simulation tool
   - Inventory management view
   - Animated charts and stats
5. **CTA** - Clean call-to-action
6. **Footer** - Links and social

### Dashboard Demo Includes

- ✅ Animated stat counters
- ✅ Real-time status updates
- ✅ Interactive topology map (click nodes)
- ✅ Tab switching with animations
- ✅ Mock path simulation
- ✅ Firewall inventory table
- ✅ Activity feed
- ✅ Responsive design

## 🚀 Quick Start

```bash
npm run build

```

## 🎯 What Makes It Different

- **No tech jargon** - Focus on what users get, not how it's built
- **Interactive demo** - Users can actually click around the dashboard
- **Real animations** - Everything moves and responds
- **Light theme** - Easy on the eyes, professional look
- **Mock data** - Looks real, works real, but it's all fake data
